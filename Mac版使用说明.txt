 YouTube 下载器 · Mac 版使用说明（v1.1）
════════════════════════════════════════════

【这是什么】
这是 Mac 专用版，功能与 Windows 版一致：
  · 下载视频（最高 4K）、仅音频（MP3/M4A/WAV）、仅字幕（SRT/TXT/LRC）
  · 自动检测字幕语言、H.264 转码、实时进度
  · 配合浏览器插件自动上传实时登录 Cookie，免手动导出 Cookie、免关浏览器

注意：本包里的 .py 是“源码”，不是成品 App。Mac 不能直接双击运行，
按下面【方式一】先跑起来；想做成双击即用的 App 见【方式二】。

──────────────────────────────
方式一：直接运行（最简单，先跑起来）
──────────────────────────────
1. 安装 Python 3（没装的话）：
     打开“终端”，输入：brew install python
   （没装 Homebrew 的话，先去 https://brew.sh 装）

2. 安装 ffmpeg 和 node（终端输入）：
     brew install ffmpeg node

3. 安装下载器需要的库（终端输入）：
     pip3 install yt-dlp curl_cffi

4. 运行（先 cd 到本文件所在文件夹，再输入）：
     python3 YouTube下载器_mac.py
   看到图形界面就成功了。

──────────────────────────────
方式二：打包成 .app（Mac 的“exe”，双击即用）
──────────────────────────────
1. 先完成方式一的 1~3 步，装好环境。

2. 安装打包工具（终端输入）：
     pip3 install pyinstaller

3. 打包（终端输入；若 ffmpeg 不在 /opt/homebrew/bin，
   先输 which ffmpeg 查看真实路径替换）：
     python3 -m PyInstaller --onefile --windowed \
       --name "YouTube下载器" \
       --icon "app.icns" \
       --add-data "/opt/homebrew/bin/ffmpeg:." \
       --add-data "/opt/homebrew/bin/ffprobe:." \
       --add-data "/opt/homebrew/bin/node:." \
       --collect-all curl_cffi \
       "YouTube下载器_mac.py"

4. 打包完成后，dist 文件夹里会生成 “YouTube下载器.app”，双击即可。

──────────────────────────────
推荐：用浏览器插件自动传登录 Cookie（和 Windows 版一样）
──────────────────────────────
YouTube 经常对未登录访问弹“人机验证”。装一次插件后，
插件会在你打开视频页时自动把实时登录 Cookie 发给本地下载器，
不用手动导出 Cookie 文件，也不用关浏览器。

第 1 步：先运行/打开下载器（让它后台开着，本地服务端口 47831）。
第 2 步：打开 Edge 或 Chrome，地址栏输入 edge://extensions
        （Chrome 输 chrome://extensions），打开“开发人员模式”，
        点“加载已解压的扩展程序”，选择本包里的「浏览器插件」文件夹。
第 3 步：在浏览器登录好 YouTube，打开视频页，点右下角红色「⬇ 下载」，
        选好画质/模式，下载器会自动接收并开始下载。

（不用插件也行：把手动导出的 Netscape 格式 cookies.txt
  放在本程序同目录，程序会自动读取。）

──────────────────────────────
使用前提（两种方式都一样）
──────────────────────────────
1. 需要加速器（全局模式），否则打不开 YouTube；程序会自动探测
   常见代理端口（7892/7890/10808 等），换加速器不用改设置。
2. 首次打开 .app 若提示“无法验证开发者”，右键点 App → 打开 → 再点“打开”
   即可（这是 macOS 对未签名程序的正常拦截，不是病毒）。
3. 保存位置：默认系统“下载”文件夹，也可点“浏览…”自选。

──────────────────────────────
常见问题
──────────────────────────────
Q：提示 Sign in to confirm you're not a bot（人机验证）？
A：① 下载器是否先打开；② 插件是否装好/重新加载；③ 浏览器是否登录
   YouTube；④ 刷新视频页再点一次。

Q：报 429 Too Many Requests（限流）？
A：YouTube 临时限流，等 1~2 分钟再下，或先换个视频。

Q：下载卡住不动 / 速度很慢？
A：多为加速器节点带宽小，换更快、延迟低的节点；程序已内置自动重试、
   30 秒超时换分片、5 路分片并发，高清建议先试 1080p。

Q：4K 下不到、只有低清晰度？
A：部分 4K 源被 YouTube 的 SABR 实验限制，属平台侧问题，非本工具故障。
